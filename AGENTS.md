## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for jkoestinger/akshually, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Coding standards

Code follows `CODING_STANDARDS.md` at the repo root. Read it before writing code. Run fmt, clippy and tests as its last section says before you push.
